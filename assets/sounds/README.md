# Engrama Sound Assets

Place your `.mp3` audio files here for the Howler.js sound system (`ui-assets.js`).

## Required files

| File | Description | Suggested search terms |
|---|---|---|
| `success.mp3` | Soft chime — UI confirmation | "Minimalist UI chime", "soft notification" |
| `error.mp3` | Low thud — error feedback | "UI error thud", "negative feedback" |
| `coin.mp3` | Ceramic clink — coin earned | "coin clink ceramic", "coin collect" |
| `streak.mp3` | Ascending whoosh — streak milestone | "whoosh ascending", "level up swoosh" |

## Free sources

- **Sonniss GDC Bundle** — Search for "UI" / "Interface" sounds
- **Freesound.org** — Tags: "Minimalist UI", "Soft Notification", "Wood Click"
- **Mixkit UI Sounds** — Section: "Smartphone"

## Notes

- Keep files under 50KB each for fast loading
- MP3 format is universally supported
- Sounds are lazy-loaded on first user interaction (no render blocking)
